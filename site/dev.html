c python-cordis

Contribute, test, ship.

python-cordis 是 MIT 开源、strict mypy、单测覆盖六大模块。下面是从拉源码到发版的完整链路。

1 · Setup

本地开发环境

克隆后可编辑模式安装,自带 dev / hmr 额外依赖。

git clone https://github.com/peroxider/python-cordis
cd python-cordis

pip install -e ".[dev,hmr]"

dev extra 提供 pytest / pytest-cov / mypy / build;hmr extra 提供 watchdog(可选)。

2 · Verify

测试、类型检查、打包

三件事一行命令;CI 也跑同一组。

命令作用
python -m mypystrict 模式类型检查(pyproject.toml [tool.mypy])
python -m pytest运行测试套件(tests/)
python -m build同时产出 sdist + wheel
 
# 一次性跑完整套验证
python -m mypy        && \
python -m pytest -q   && \
python -m build
3 · Author

写你自己的插件

插件就是一对 inject + apply。下面是 minimum viable plugin 的完整形态。

from python_cordis import Context, HookRegistry
from python_cordis.core.hook import hookimpl, hookspec

@hookspec
def on_message(text): ...

class Greeter:
    name   = "greeter"
    inject = ()                              # 不需要任何依赖 → 立即激活

    def apply(self, ctx):
        @hookimpl
        def on_message(text):
            print(f"hi, {text}!")
        ctx.on(hooks, "on_message", on_message)
        ctx.effect(lambda: print("greeter down"))  # 可逆拆卸

想看更多范例?核心概念页 讲清了可逆效应 / 反应式余效应 / Context / Fiber / 四种 hook 模式, 快速开始 有完整可跑通的 5 分钟示例。

4 · Ship

发版与贡献

本项目遵循 Conventional Commits;版本号手动维护于 pyproject.toml。

▲

TestPyPI 验证

python -m build + twine upload --repository testpypi dist/* 先在测试环境试一遍,避免污染正式索引。

★

正式发版

改 pyproject.toml 中的 version + 同步 __version__,打 tag 推 twine upload dist/*。

⇄

提 PR

fork → feature branch → commit → PR。CI 会跑 mypy + pytest,需要保持 strict 模式干净。

详细贡献指南见 GitHub repo。 License: MIT · Python ≥ 3.10。
